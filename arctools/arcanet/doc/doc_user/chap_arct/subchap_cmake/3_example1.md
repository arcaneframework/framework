# Simple example {#arcanetdoc_arct_cmake_example1}

[TOC]

File `testlist.arct`:

```json
{
  "versions": {
    "_": 1,
    "arcane": 1,
    "arccher": 1
  },
  "general": {
    "_": {
      "name": "Basic run"
    },
    "arcane": {
      "dataset": "config_2D_diagonal_circle.arc",
      "options": {
        "MaxIteration": "10"
      }
    }
  }
}
```

File `tests.cmake`:

```cmake
arct_config_create_or_edit_general(OVERWRITE_ARCT)
arct_config_define_name(NAME "Basic run")
arct_arcane_dataset(PATH "config_2D_diagonal_circle.arc")
arct_arcane_option(ADD "MaxIteration" VALUE "10")
arct_config_create_or_edit_end()

arct_to_ctest()
```

Generated tests:

```shell
ctest -N

#None
```

Let's revisit the ARCT example \ref arcanetdoc_arct_general.

We have three editable pieces of information in this ARCT file: one piece of information of type `config`
and two pieces of information of type `arcane`.

The functions starting with `arct_config_...` concern the ARCT reserved block (`_`).

The functions starting with `arct_arcane_...` concern the Arcane reserved block (`arcane`).

The functions starting with `arct_arccher_...` concern the ArcCher reserved block (`arccher`).

As there is no base case, no test is generated by the `arct_to_ctest()` function. This kind of file can
be used to be read by Arcane directly.
