# Projet ArcaNet

- ArcaNet (environnement de tests) :
  - ArcaNet file (.arct) : schéma de fichier json décrivant un lancement de cas
  - ArcCher  : lanceur de programmes utilisant les .arct
  - Schedane : scheduler de cas utilisant les .arct (~CTest)
  - GUIane   : interface web permettant de piloter Schedane (et peut-être un jour Arcane)
